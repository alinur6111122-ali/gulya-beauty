APK yaratmaq:
1. Android Studio-nu kompüterə quraşdırın.
2. File > Open seçin və bu qovluğu açın.
3. Gradle sync tamamlanmasını gözləyin.
4. Build > Build Bundle(s) / APK(s) > Build APK(s) seçin.
5. APK app/build/outputs/apk/debug/app-debug.apk yolunda yaranacaq.
6. APK-nı Android telefonuna göndərib quraşdıra bilərsiniz.

Qeyd: Bu mühitdə Android SDK/Gradle olmadığı üçün APK binary faylı burada kompilyasiya edilməyib. Bu ZIP hazır Android Studio layihəsidir, APK faylı deyil.
